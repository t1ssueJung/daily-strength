# 하루 10분 근력운동 · 명단 체크표

관리자가 명단을 등록하면 참가자는 이름을 입력하지 않고 표에서 자기 이름의 날짜 칸을 바로 체크합니다. 최근 7일 칸을 체크하거나 취소할 수 있으며 제외일은 건너뜁니다. 날짜 기준은 한국 시간입니다.

## 설치 및 업데이트

1. [Supabase](https://supabase.com/dashboard)의 **SQL Editor → New query**에 `setup.sql` 전체를 붙여넣고 실행하세요. 처음이면 새 프로젝트를 만들어 진행합니다. 이전 공용 버전을 이미 사용 중이면 **같은 Supabase 프로젝트**에서 실행하세요. 기존 반 링크, 관리자 비밀번호, 제외일이 유지됩니다.
2. 처음 설치하는 경우 Supabase **Connect**에서 복사한 프로젝트 URL과 `sb_publishable_`로 시작하는 **Publishable key**를 `config.js`에 입력하세요. 업데이트하는 경우 이미 GitHub에 올린 `config.js`를 그대로 사용하세요.
3. GitHub Pages 배포 폴더에 `index.html`, `app.js`, `config.js`를 올리세요. 기존 사이트를 업데이트한다면 `index.html`과 `app.js`를 교체하세요. `setup.sql`은 Supabase에서만 실행하세요. 새 GitHub Pages 사이트는 [배포 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)을 참고하세요.

## 명단 등록과 공유

- 관리자 링크는 **배포 주소 + `#admin=` + SQL 실행 결과의 `admin_id`**입니다. 관리자 링크는 관리자만 보관하세요. 새 반의 초기 관리자 비밀번호는 `123456!`입니다.
- 로그인한 다음 **참가자 명단**에 한 줄에 한 명씩 붙여넣고 **명단 등록**을 누르세요. 같은 표시 이름은 하나로 처리됩니다. 동명이인은 번호나 별명을 붙여 구분하세요.
- 관리자 화면의 **참가자 화면 열기** 링크를 복사해 공유하세요. 직접 만들려면 **배포 주소 + `#room=` + SQL 실행 결과의 `room_id`**를 사용하세요.
- 잘못 등록한 이름은 **명단에서 빼기**를 누르세요. 같은 이름을 다시 등록하면 그 이름의 체크 기록이 돌아옵니다. **날짜 제외**에서는 쉬는 날을 지정하거나 해제할 수 있어요.
- 참가자는 날짜 칸을 한 번 눌러 체크하고 다시 눌러 취소할 수 있어요. 참가자 링크로 들어온 사람은 반의 명단과 체크를 보고 칸을 바꿀 수 있으므로 링크는 반에만 공유하세요.

## 이전 기록

이전 공용 버전의 기록은 기존 프로젝트에 보관됩니다. 새 명단에 **이전과 같은 표시 이름**을 처음 등록하면 해당 이름의 공용 기록이 날짜별로 이어집니다. 이름 뒤에 번호나 별명을 새로 붙이면 별도 이름으로 처리됩니다. 공용 저장소 없이 브라우저에만 남아 있던 기록은 자동으로 옮겨지지 않습니다.
